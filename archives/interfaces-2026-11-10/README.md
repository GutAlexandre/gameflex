# Interfaces archivées

Copie intégrale des interfaces au commit `84c6683619cf9752e4e099eb548dc796a2fae470`, avant l’interface unique. Les 22 compositions, styles, registre historique, composants partagés et références aux crédits sont conservés dans `experience/`. Le manifeste SHA-256 permet de vérifier cette copie. Aucun fichier de bibliothèque, compte ou sauvegarde n’est déplacé.

Pour restaurer une version exécutable complète dans un worktree séparé :

```sh
git worktree add ../gameflex-interfaces-archive 84c6683619cf9752e4e099eb548dc796a2fae470
```

Les préférences conservent l’ancien identifiant dans `archivedInterface`. Les six anciennes destinations restent reconnues. Les sources et crédits des illustrations restent dans les métadonnées existantes ; aucune illustration externe n’est ajoutée à cette archive.
