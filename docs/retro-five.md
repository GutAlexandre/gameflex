# Cinq interfaces centrées sur la bibliothèque

Disponibles dans **Paramètres › Changer d’interface** :

- **Horizon** (`station`) : console en panorama et rail de systèmes ; galerie de jeux.
- **Signal CRT** (`crt`) : moniteur cathodique, liste de systèmes ; répertoire et aperçu.
- **La collection** (`shelf`) : étagère d’objets ; cartouches avec jaquettes.
- **Orbitale** (`orbit`) : systèmes sur une carte orbitale ; tableau de mission.
- **Borne Arcade** (`arcade`) : marquise, écran et panneau de commande ; sélection arcade.

Chaque interface propose d’abord uniquement les consoles possédées, puis les jeux
installés pour la console choisie. Aucun fournisseur de catalogue n’est interrogé
pour ce parcours. Les dix interfaces précédentes restent disponibles ; le choix
actuel n’est pas remplacé. Les photos et jaquettes existantes sont réutilisées,
avec leurs crédits. Les photos de matériel bénéficient d’un filtre SVG de détourage
à l’affichage ; les originaux restent inchangés.

Les compositions changent pour les petits écrans, avec focus directionnel et retour
au jeu précédent. Les propositions exportées montrent les vues console et jeux,
en format TV 1600 × 900 et téléphone 390 × 844. Ce sont des captures de l’application,
pas des illustrations de jeux inventées. Les captures de test utilisent une
préférence locale interceptée et ne modifient pas le choix enregistré du compte.
